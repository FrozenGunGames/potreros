# Potreros El Campamento

Offline learning game for the 20 fields (potreros) of Estancia El Campamento, Río Negro, Uruguay, with live GPS position.

- Open https://frozengungames.github.io/potreros/ in Safari on the iPhone → Share → Add to Home Screen.
- Open the home-screen app once with internet; after that it works offline.
- Satellite image: IDE Uruguay orthophoto 2019, resampled to 1 m.
